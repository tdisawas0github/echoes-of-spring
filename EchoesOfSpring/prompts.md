## Tips

- **Consistency:** Generate all images in the same session or with the same seed/style settings to maintain visual consistency.
- **Transparency:** For character sprites, use a tool like [remove.bg](https://www.remove.bg/) or your AI tool's background removal if it doesn't support transparent output natively.
- **Upscaling:** If your generator outputs at lower resolution, use an AI upscaler (e.g., Real-ESRGAN) to reach the target sizes.
- **Filenames:** Ren'Py matches `show sakura happy` to a file named `sakura happy.png` or `sakura_happy.png` — either works.
